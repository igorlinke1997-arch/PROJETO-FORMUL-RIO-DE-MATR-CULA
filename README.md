 Projeto Formulário de Matrícula

Este projeto consiste no desenvolvimento de uma página web de **Formulário de Matrícula**, criada com **HTML e CSS**.

O objetivo do projeto é aplicar conceitos de desenvolvimento web, organização de formulários, estilização de componentes e construção de uma interface organizada e intuitiva para o preenchimento de informações de matrícula.

 Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

 Funcionalidades

O formulário permite a organização e o preenchimento de informações necessárias para uma matrícula.

O projeto trabalha com diferentes elementos de formulário e componentes visuais, como:

- Campos de texto;
- Seleção de opções;
- Campos de data;
- Botões;
- Ícones;
- Validação visual de campos;
- Organização das informações em seções;
- Interface estilizada utilizando CSS.

 Interface

A interface foi desenvolvida buscando manter uma apresentação limpa, organizada e de fácil utilização.

Os estilos foram separados em diferentes arquivos CSS para facilitar a organização e manutenção do projeto.

 Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no **Visual Studio Code**.
3. Localize o arquivo `Index.html`.
4. Abra o arquivo no navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto.
